Before you start

Connect your assistant to Cadence once. Pick your app:

  1. In Cadence, open Settings → Assistants and click Install next to Claude.
  2. Quit and reopen the Claude desktop app. cadence now shows up in its list of tools.
  3. Start a Cowork task and paste a prompt from the catalog below.
  4. For prompts marked Scheduled, ask Cowork to turn it into a scheduled task, for example "run this every weekday at 08:30". Scheduled tasks run while your Mac is awake and Claude is open.

Cowork can mix Cadence with your other connectors (Google Drive, Gmail, Slack, Notion…). That's what the Uses your other connectors badge means. Prefer to edit the file yourself? Add this to ~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "cadence": {
      "command": "/Applications/Cadence.app/Contents/MacOS/cadence-mcp",
      "args": []
    }
  }
}
  1. Click Install next to Claude Code in Cadence's Settings → Assistants, or run:
claude mcp add --scope user cadence -- "/Applications/Cadence.app/Contents/MacOS/cadence-mcp"
  1. Paste a prompt into any session. Or save the downloaded .md file in ~/.claude/commands/ and it becomes a slash command, like /cadence-morning-briefing.
  2. For Runs in the background prompts, keep the session open while it loops. For Scheduled ones, use /loop or your own scheduler.
  1. Click Install next to Cursor in Cadence's Settings → Assistants, or add this to ~/.cursor/mcp.json:
{
  "mcpServers": {
    "cadence": {
      "command": "/Applications/Cadence.app/Contents/MacOS/cadence-mcp",
      "args": []
    }
  }
}
  1. Check cadence is switched on in Cursor's MCP settings, then paste a prompt into the chat in Agent mode.
  2. Cursor has no scheduler, so run Scheduled prompts when you want them. Background prompts loop while the chat is running.
  1. Click Install next to Windsurf in Cadence's Settings → Assistants, or add this to ~/.codeium/windsurf/mcp_config.json:
{
  "mcpServers": {
    "cadence": {
      "command": "/Applications/Cadence.app/Contents/MacOS/cadence-mcp",
      "args": []
    }
  }
}
  1. Refresh MCP servers in Windsurf, then paste a prompt into Cascade.
  2. Like Cursor, run Scheduled prompts by hand. Background prompts loop while Cascade is working.
  1. Install Gemini CLI, then click Install next to Gemini CLI in Cadence's Settings → Assistants, or run this to add Cadence for every folder you work in. Moved to Antigravity CLI? Use the Antigravity tab instead.
gemini mcp add --scope user cadence /Applications/Cadence.app/Contents/MacOS/cadence-mcp

Or add it to ~/.gemini/settings.json yourself:

{
  "mcpServers": {
    "cadence": {
      "command": "/Applications/Cadence.app/Contents/MacOS/cadence-mcp",
      "args": []
    }
  }
}
  1. Start gemini and type /mcp: cadence should be listed with its tools. Then paste a prompt from the catalog.
  2. Gemini CLI asks before it runs each tool. Cadence still shows its own confirmation card for anything that changes your calendar.
  3. For Scheduled prompts, run Gemini CLI from your own scheduler (cron, launchd or Shortcuts) with gemini -p "…". Unattended runs can't stop to ask, so check Gemini CLI's docs for allowing Cadence's read-only tools first. Runs in the background prompts loop while the session stays open.
What about the Gemini desktop app?

As of November 2026, the Gemini app's custom connectors take a remote server URL, and Cadence only runs on your Mac, with no network port. So use Gemini CLI or Antigravity. Don't put Cadence on a public URL with a tunnel: that would open your calendar, and actions like replying to invites, to the internet.

  1. Click Install next to Antigravity in Cadence's Settings → Assistants and let it restart Antigravity, then skip to step 3. To do it by hand: Antigravity's app, IDE and CLI share one MCP file, ~/.gemini/config/mcp_config.json (older versions use ~/.gemini/antigravity/mcp_config.json). To open it in the IDE, click … at the top of the agent panel, then MCP Servers → Manage MCP Servers → View raw config. In the app, Customizations → Installed → MCP Servers has a button that copies the file's path.
  2. Add Cadence and save:
{
  "mcpServers": {
    "cadence": {
      "command": "/Applications/Cadence.app/Contents/MacOS/cadence-mcp",
      "args": []
    }
  }
}
  1. Restart the server from the MCP Servers list (or type /mcp in Antigravity CLI) and check cadence shows its tools. Then paste a prompt into the agent.
  2. Antigravity asks before running each MCP tool. You can allow Cadence's read-only tools in Antigravity's permissions, for example mcp(cadence/get_agenda). Cadence still shows its own confirmation card for anything that changes your calendar.
  3. Background prompts loop while the agent keeps working. Run Scheduled ones by hand, or from your own scheduler if you use the CLI.

Using a workspace instead? The same JSON also works in .agents/mcp_config.json inside that project.

  1. Cadence works with any app that can start a local (stdio) MCP server. Most use the same JSON as Claude; look for "MCP servers" in your app's settings or docs and add:
{
  "mcpServers": {
    "cadence": {
      "command": "/Applications/Cadence.app/Contents/MacOS/cadence-mcp",
      "args": []
    }
  }
}
  1. Every prompt in the catalog starts with "Using the Cadence tools…" and names the tools it needs, so it doesn't depend on Claude.

Apps that can only connect to remote MCP servers over the internet can't reach Cadence, and that includes the Gemini desktop app (use Gemini CLI or Antigravity instead). That's by design: Cadence never opens a network port, and your calendar stays on your Mac.

Write your own

Your assistant sees these tools. Name them in your prompt and it'll know what to do.

👀 Read free to call

get_agenda today or tomorrow · get_next_meeting · get_current_meeting · list_invites · list_clashes · find_free_time (inside your working hours, with breaks kept clear) · list_calendars · get_status (presenting, on a call)

✋ Act asks you first

respond_to_invite · set_event_color (Google) · join_meeting · hide_from_panel · snooze_alert. Each pops an Allow / Deny card in Cadence. Unanswered requests are denied after a minute.

📎 Attach switch off any time

add_enrichment · update_enrichment · remove_enrichment · clear_enrichments · get_enrichments (with your ticks, marks and entries). Up to 20 per meeting; all_occurrences puts one on every meeting in a series.

📡 Listen

wait_for_event waits up to 5 minutes for meeting.starting_soon, meeting.started, meeting.ending_soon, meeting.ended, invite.new, meeting.changed, meeting.canceled, clash.new, status.presenting, status.on_call, enrichment.changed and enrichment.bingo.

Cadence also ships four ready-made prompts your app may list on its own: daily_briefing, prepare_for_meeting, triage_invites and enrich_meeting. Cadence can't create or delete events. For that, pair it with your calendar connector. Setup trouble? See Help.

🔒 You stay in charge

Assistants reach Cadence through a private socket on your Mac, with no network port. Anything that changes your calendar or joins a call asks you first, and Settings → Assistants → Activity shows everything they did. What an assistant reads is then handled by that assistant and its provider.
