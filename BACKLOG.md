# Backlog

Ideas that are parked, not planned. Newest decisions at the top.

## 📌 Pinned — needs design first

- **Meeting notes shortcut.** "Open notes" on an event that creates or opens a note named after the meeting.
  Everyone's notes setup differs (Apple Notes, Obsidian/Markdown folders, Notion, Bear, Craft…), so this
  needs a pluggable "notes target" design before building: where notes live, file naming, templates
  (attendees, agenda, join link), and whether to pre-fill from the invite.

## 🗂️ Backlog

- **Mac widgets.** Notification Centre / desktop widget showing the next meeting and today's agenda.
  The iPhone app now has an Xcode project with a WidgetKit extension; a macOS target could reuse it.
- **RSVP and colours on iPhone.** The phone's providers already support replies and colours; it needs the UI.

## ⏭️ Skipped

- **Focus / Do Not Disturb while in meetings.** macOS has no public API for apps to toggle Focus; it would
  need user-installed Shortcuts and is too fiddly to be worth it.
